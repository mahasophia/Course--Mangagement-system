Module 1 : Introduction to Python

Python is a high-level, interpreted programming language. It is easy to learn because of its simple syntax. Python is widely used in web development, data science, artificial intelligence, automation and software development.

Module 2 : Variables & Data Types

Variables store data in memory. Python supports integer, float, string, boolean, list, tuple, dictionary and set data types.

Module 3 : Operators & Loops

Operators are used to perform arithmetic, comparison, logical and assignment operations. Loops help execute the same block of code multiple times. Python supports for and while loops.

Module 4 : Functions

Functions are reusable blocks of code. They help reduce repetition and make programs easy to understand and maintain. Python provides built-in and user-defined functions.

Module 5 : Object-Oriented Programming

Object-Oriented Programming (OOP) organizes code using classes and objects. The main concepts are Class, Object, Inheritance, Polymorphism, Encapsulation and Abstraction.
