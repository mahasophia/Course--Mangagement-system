Module 1 : Introduction to Java

Java is a high-level, object-oriented programming language. It is platform-independent because Java programs run on the JVM. Java is widely used for web applications, Android development and enterprise software.

Module 2 : Variables & Data Types

Variables are used to store values. Java supports int, float, double, char, boolean and String data types.

Module 3 : Operators & Control Statements

Java provides arithmetic, relational, logical and assignment operators. Control statements include if, else, switch, for and while loops.

Module 4 : Classes & Objects

Java follows Object-Oriented Programming. A class is a blueprint and an object is an instance of a class. Methods and constructors define object behavior.

Module 5 : Exception Handling

Exception handling helps manage runtime errors. Java uses try, catch, finally, throw and throws keywords.
