Module 1 : HTML Basics

HTML (HyperText Markup Language) is used to create the structure of web pages using headings, paragraphs, images, links and forms.

Module 2 : CSS

CSS (Cascading Style Sheets) is used to style web pages by adding colors, fonts, layouts and animations. CSS makes websites attractive and responsive.

Module 3 : JavaScript Basics

JavaScript adds interactivity to web pages. It is used for form validation, animations, DOM manipulation and dynamic content.

Module 4 : Bootstrap

Bootstrap is a CSS framework used to build responsive and mobile-friendly websites quickly. It provides ready-made components like buttons, cards, forms and navigation bars.

Module 5 : Responsive Web Design

Responsive Web Design makes websites look good on desktops, tablets and mobile phones. CSS Media Queries and Bootstrap Grid System help create responsive layouts.
