# 🎓 Student Course Management and Learning Progress Tracking System

## 📖 Project Overview

The **Student Course Management and Learning Progress Tracking System** is a Full Stack Web Application designed to simplify online course management and learning. It allows students to register, browse courses, enroll in courses, access learning materials, track course progress, complete quizzes, and download certificates. Administrators can manage courses, students, and monitor learning progress. :contentReference[oaicite:0]{index=0}
